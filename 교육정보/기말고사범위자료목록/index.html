현재 학교 안내를 기준으로 범위를 적으세요

교과서 쪽수, 단원, 유인물과 평가 안내를 대조합니다. 친구의 목록을 참고할 수 있지만 최종 범위는 본인이 받은 공식 안내와 수업 자료로 확인하세요.

범위가 바뀌거나 추가 안내가 있으면 날짜를 남겨 수정합니다. 과거 시험 범위나 문제집 목차를 이번 범위와 같다고 가정하지 않습니다.

자료가 있는지와 공부했는지를 구분하세요

표에 단원, 자료 위치, 할 과제, 이해 상태를 별도로 둡니다. 유인물을 구하는 일과 그 내용을 설명하는 일은 다른 과제이므로 같은 완료 표시로 합치지 않습니다.

자료가 많으면 파일명이나 묶음에 단원·날짜를 적어 찾기 쉽게 정리합니다. 자료를 예쁘게 다시 만드는 데 시간을 쓰기보다 실제로 필요한 부분을 확인하세요.

이해 상태는 작은 과제로 판단하세요

읽었음과 이해했음을 같은 뜻으로 보지 않습니다. 대표 질문에 자료 없이 답하거나 새 문제를 풀어 본 뒤 설명 가능, 적용 필요, 질문 필요로 표시할 수 있습니다.

상태 분류는 점수를 보장하는 등급표가 아닙니다. 다음 공부를 정하기 위한 기록이며, 확인 과제가 달라지면 상태도 다시 바꿀 수 있습니다.

복습 계획에 질문과 재확인을 넣으세요

적용이 필요한 내용은 유사 과제로, 질문이 필요한 내용은 원래 풀이와 함께 설명 요청으로 연결합니다. 이미 설명 가능한 내용도 이후 짧은 확인으로 유지할 수 있습니다.

범위가 넓다고 임의로 단원을 버리기보다 학교 일정과 사용 시간을 보고 순서를 정합니다. 빠진 자료와 미해결 질문을 마지막 점검에서도 확인하세요.

직접 적용해 보는 예시

가상 표에서 “2단원 / 학교 유인물 3장 / 내용 비교 질문 / 질문 필요”라고 적습니다. 먼저 없는 유인물 한 장을 확보하고, 이해가 불명확한 비교 문항은 교사에게 질문합니다. 자료 확보와 개념 확인을 다른 완료 칸으로 남깁니다.
