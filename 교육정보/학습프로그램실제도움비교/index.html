학생의 필요를 비교 기준으로 만드세요

개념 설명이 필요한지, 혼자 풀이 시작이 어려운지, 계획 실행을 점검해야 하는지 나눕니다. 모든 학생에게 같은 수업 방식이 가장 좋다고 가정하지 않습니다.

최근 풀이와 학교 일정이 있으면 상담이 구체적입니다. 프로그램 이름을 비교하기 전에 어떤 과제에서 어떤 지원이 필요한지 정해 두세요.

수업 안의 실제 행동을 물어보세요

설명 뒤 학생이 혼자 적용할 시간이 있는지, 막힌 문제를 질문할 수 있는지, 교사가 무엇을 보고 다음 과제를 정하는지 확인합니다. 그룹 크기나 수업 형태 하나만으로 지도 내용을 단정하지 않습니다.

맞춤 지도가 있다면 무엇을 기준으로 진도와 난도를 바꾸는지 물어봅니다. 현재 지점의 개설 과목·학년과 실제 운영 방식은 해당 지점에서 확인하세요.

피드백 이후 과제를 확인하세요

틀린 이유를 설명해 주는 것과 학생이 수정한 뒤 이해를 재확인하는 것은 다른 단계입니다. 피드백이 어떤 과제와 재점검으로 이어지는지 사례 자료를 요청할 수 있습니다.

특정 수강생의 실적만으로 자신의 결과를 예상하지 않습니다. 학생에게 적용할 목표와 확인 방법, 필요한 학습량이 구체적인지 살펴보세요.

수업 밖 일정과 소통도 비교하세요

통학, 숙제, 질문 가능 시점과 학부모 소통 방식을 함께 확인합니다. 여러 수업을 더해도 복습 시간이 부족하면 배운 것을 적용하기 어려울 수 있습니다.

상담 내용을 같은 표에 적고 첫 수업 뒤 다시 대조합니다. 설명한 방식과 실제 지도, 학생의 수행 결과가 연결되는지 보고 다음 결정을 합니다.
