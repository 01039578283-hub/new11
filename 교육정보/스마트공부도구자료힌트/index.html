도구의 역할을 구분하세요

자료 보관, 계획 기록, 개념 설명, 풀이 힌트는 서로 다른 역할입니다. 하나의 도구에 모든 기대를 걸기보다 현재 가장 불편한 과정을 골라 활용하세요.

새 서비스의 기능과 비용·정보 공개 범위는 현재 안내로 확인합니다. 좋은 도구를 찾는 시간보다 과제를 수행하고 확인하는 시간이 남는지 살펴봅니다.

자료 이름과 분류를 단순하게 정하세요

“과목_단원_날짜_자료종류”처럼 찾을 단서를 남기고, 이번 과제에 필요한 자료를 별도로 묶을 수 있습니다. 분류가 지나치게 복잡하면 정리 자체가 부담이 됩니다.

사진이나 스캔은 글자가 읽히는지 확인하고 실제 수업 자료의 순서와 연결합니다. 자료 공유는 학교·제공자의 이용 안내를 확인하고 필요한 범위에서 하세요.

힌트를 받기 전 자기 시도를 남기세요

문제 조건과 시도한 식, 막힌 줄을 적은 뒤 어떤 힌트가 필요한지 묻습니다. 전체 답안을 먼저 받으면 자신의 이해가 어디까지였는지 확인하기 어렵습니다.

도구가 제시한 설명이 원자료의 조건과 맞는지 대조합니다. 특히 자동 생성 설명은 오류가 있을 수 있으므로 교과서·교사 설명과 검산으로 확인하세요.

도움 뒤 독립 수행을 확인하세요

힌트에서 배운 원리를 말하고 도구를 닫은 뒤 새 문제를 풀어 봅니다. 답을 기억해 그대로 쓴 것인지 다른 조건에서도 원리를 쓴 것인지 구분합니다.

학부모는 기기 사용 시간만 보지 말고 자기 시도, 받은 힌트, 최종 재풀이를 함께 확인할 수 있습니다. 필요한 지원이 줄거나 달라지는지를 대화 자료로 남기세요.

직접 적용해 보는 예시

가상 기록입니다. 수학 조건을 정리한 사진과 막힌 줄을 먼저 남깁니다. 도움 설명을 받은 뒤 교과서의 정의와 대조하고, 다른 수의 문제를 도구 없이 풉니다. 자료 파일에는 단원과 날짜를 붙여 다음 복습 때 쉽게 찾도록 합니다.
