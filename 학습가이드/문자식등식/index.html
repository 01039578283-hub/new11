문자식과 등식, 부호 실수를 이유로 고치기

중학생고등학생

온담학습 학습안내 · 작성·자료 확인 2026-10-04

문자식과 등식은 “이항하면 부호가 바뀐다”만 외우기보다 양변에 같은 연산을 했는지 확인하세요. 괄호가 있는 식은 어느 항에 무엇을 곱하는지 표시하고, 구한 값을 원래 식에 대입합니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

이항이라는 표현을 사용할 수 있지만 그 바탕에는 등식을 유지하는 연산이 있습니다. 풀이를 한 줄씩 나누면 괄호 해제와 등식 변형을 한꺼번에 하다가 생기는 오류를 찾기 쉽습니다.

관련 학습 방법의 참고 범위는 IES 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 항과 괄호 범위 표시하기

    3(x − 2)에서 3이 x와 −2 모두에 곱해짐을 표시합니다. 3x − 2처럼 괄호의 일부만 계산하지 않았는지 확인합니다.

  2. 같은 연산을 양쪽에 쓰기

    x − 2 = 4라면 양변에 2를 더하는 과정을 적습니다. 식을 옮기는 말보다 무엇을 더하거나 나누었는지를 설명합니다.

  3. 한 줄에 한 변화만 남기기

    익숙하지 않을 때는 괄호 해제, 항 정리, 나눗셈을 나누어 적습니다. 과정이 안정되면 줄을 줄이되 이유는 말할 수 있어야 합니다.

  4. 원래 식에 대입하기

    구한 값을 처음 식에 넣어 양변이 같은지 봅니다. 중간에 잘못 변형한 식에만 대입하면 오류를 발견하지 못할 수 있습니다.

PRACTICE EXAMPLE

3(x − 2) = 12의 두 풀이

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 문제입니다. 3(x − 2) = 12를 풀고 두 방법을 비교해 보세요.

두 풀이와 검산 보기

방법 1: 양변을 3으로 나누면 x − 2 = 4, 양변에 2를 더하면 x = 6입니다. 방법 2: 괄호를 풀면 3x − 6 = 12, 양변에 6을 더하고 3으로 나누어 x = 6입니다. 원래 식에 대입하면 3(6 − 2) = 12로 같습니다.

답을 기억하지 않은 새 식으로 확인하기

계수가 달라져도 같은 원리로 식을 바꾸는지 확인하세요. 여러 계산을 한 줄에 합치기 전에 괄호를 어떻게 풀었는지와 양변에 어떤 연산을 했는지를 구분합니다. 검산에서 양변이 다르면 무조건 마지막 계산만 고치지 말고 처음 식부터 변형을 비교하세요. 이항과 나눗셈이 섞이는 단계에서 도움을 받았다면 그 부분을 따로 기록합니다.

다른 과제로 한 번 더

2(x + 4) = 18을 풀되, 양변에 한 연산을 각 줄 옆에 적습니다. 마지막에는 처음 식에 구한 값을 넣어 확인하세요.

확인 방향 보기

양변을 2로 나누면 x + 4 = 9, 양변에서 4를 빼면 x = 5입니다. 2(5 + 4) = 18로 확인됩니다. 풀이가 다르더라도 등식이 유지되는 이유와 원래 조건이 맞는지 확인하세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 괄호 안 모든 항을 확인했다.
  • 양변에 적용한 연산을 설명했다.
  • 나누는 수가 0이 아닌지 확인했다.
  • 처음 식으로 검산했다.

자주 묻는 질문

사용할 수 있습니다. 다만 부호 변화가 양변에 같은 연산을 한 결과임을 이해하고 설명할 수 있는지 확인하세요.

검산하면 풀이를 생략해도 되나요?

검산은 조건 확인입니다. 풀이 이유를 설명하거나 과정 작성을 요구하는 문제에서는 필요한 단계도 남겨야 합니다.

부호 실수는 계산 연습만 하면 되나요?

괄호 범위와 음수의 의미, 양변 연산을 구분해 보세요. 오류가 난 정확한 단계에 맞춰 연습을 정하는 것이 좋습니다.
