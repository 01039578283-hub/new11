선행 여부는 교재를 끝낸 양보다 현재 개념을 설명하고 새로운 조건에도 혼자 적용하는지로 살펴보세요. 새 과정에 필요한 이전 개념과 학교 진도를 확인한 뒤 복습과 새 학습의 범위를 정합니다.

먼저 살펴볼 점

앞선 내용을 접했더라도 해설을 본 문제만 풀 수 있다면 준비가 더 필요할 수 있습니다. 모든 학생에게 같은 선행 속도를 정하지 말고 지금의 이해와 실제 생활 부담을 함께 보세요. 새 과정 선택은 실제 과목명과 학교 안내를 기준으로 합니다.

관련 학습 방법의 참고 범위는 IES 참고자료 · EEF 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 현재 범위를 설명하게 하기

    이미 배운 대표 개념과 풀이 이유를 자료 없이 말합니다. 답만 맞히는지 왜 가능한지 설명하는지를 구분합니다.

  2. 조건을 바꿔 적용하기

    수나 조건이 조금 다른 유사 문제를 풀어 봅니다. 해설을 기억해 맞히는 것과 개념을 적용하는 것을 나누어 확인합니다.

  3. 새 과정의 선수 개념 찾기

    새 단원의 예제에서 필요한 이전 개념을 확인합니다. 부족한 내용이 있다면 새 진도와 별도로 보완 과제를 정합니다.

  4. 분량과 재확인 계획 정하기

    학교 과제와 복습이 밀리지 않는 범위로 시작합니다. 다른 날 다시 설명한 결과와 부담을 보고 속도와 범위를 조정합니다.

PRACTICE EXAMPLE

진도 완료와 이해를 나누는 확인

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 예시입니다. 일차방정식 단원을 끝냈더라도 “양변에 같은 수를 더하면 등식이 유지된다”는 이유를 설명하는지 확인합니다.

익숙한 2x + 3 = 11에서 x = 4를 구한 뒤 3x − 2 = 10도 혼자 풀어 x = 4가 되는지 봅니다. 이 두 문제만으로 전체 준비를 판정하는 검사는 아니며 확인 방법의 예시입니다.
