학부모

온담학습 학습안내 · 작성·자료 확인 2026-10-04

학원 비교는 학생의 현재 필요와 실제 수강 조건을 같은 표에 놓고 확인하세요. 과목·학년·시간·교습비와 함께 수업에서 이해를 어떻게 확인하고 상담으로 무엇을 전달하는지 질문합니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

홈페이지의 프로그램 소개와 현재 운영 조건은 다를 수 있습니다. 가까운 학교명이나 시설 사진만으로 학교별 지도나 현재 반 편성을 단정하지 마세요. 확인하지 못한 항목은 미확인으로 남겨 비교해야 합니다.

관련 학습 방법의 참고 범위는 EEF 참고자료 · EEF 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 학생의 필요를 먼저 적기

    현재 과목과 범위, 혼자 가능한 부분과 필요한 도움을 적습니다. 막연한 성적 향상 대신 지금 어려운 단계부터 상담 질문을 정합니다.

  2. 수강 조건을 동일 항목으로 확인하기

    정확한 과목과 학년, 현재 반 편성, 가능한 시간과 교습비를 확인합니다. 포함된 서비스와 별도 비용은 실제 안내에서 구분합니다.

  3. 이해 확인과 피드백을 질문하기

    설명 후 혼자 풀어 보는지, 오답의 원인을 어떻게 확인하는지, 보호자에게 어떤 내용을 어떤 방식으로 전달하는지 묻습니다. 운영을 직접 확인하기 전에는 있다고 단정하지 않습니다.

  4. 확인 사실과 인상을 나누기

    답변 받은 항목과 아직 확인할 항목을 분리합니다. 학생의 이동과 생활 부담도 함께 보고 실제 제공 범위로 비교합니다.

PRACTICE EXAMPLE

미확인 항목을 남긴 비교 메모

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 비교 예시입니다. A의 “현재 중2 수학 반 시간 확인”, B의 “프로그램 소개만 확인, 반 편성 문의 필요”를 같은 상태로 취급하지 않습니다.

“피드백이 좋아 보임”이라는 인상 대신 어떤 자료를 언제 전달하는지 실제 답변을 기록합니다. 특정 학원을 평가하거나 우열을 정한 사례가 아닙니다.

확인한 답과 광고 표현을 구분하기

비교표에 있는 항목의 확인 근거를 짧게 남겨 보세요. 홈페이지 소개에서 본 내용인지, 현재 지점 상담에서 받은 답인지, 아직 문의하지 않은 내용인지 구분합니다. 일반 프로그램의 대상 학년이 해당 지점의 모든 개설 학년을 뜻하지는 않습니다. 비용도 지역 공통 참고표와 실제 적용 교습비를 구분해서 확인하세요. 성적 향상이나 학교별 출제 경향에 대한 표현은 학생의 필요에 맞는 실제 지도 범위와 별도로 살펴보고 결과를 보장하는 자료로 취급하지 않습니다.

다른 과제로 한 번 더

비교하려는 지점마다 과목·학년, 현재 시간과 비용, 이해 확인 방식을 같은 세 칸에 적습니다. 각 칸 옆에는 확인한 자료나 답변, 문의 필요 상태를 남깁니다.

확인 방향 보기

빈칸을 막연한 인상으로 채우지 않고 동일한 항목으로 비교했는지 봅니다. 학생의 이동과 학교 과제에 맞는 조건도 포함하며, 특정 프로그램 이름만으로 제공 범위를 판단하지 않도록 질문을 보완하세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 학생의 필요를 기준으로 질문했다.
  • 현재 운영과 프로그램 소개를 구분했다.
  • 교습비와 포함 범위를 확인했다.
  • 미확인 항목을 임의로 채우지 않았다.

자주 묻는 질문

학교가 가까우면 내신 지도를 하나요?

거리나 학교명 목록만으로 판단할 수 없습니다. 해당 과목과 학교 자료를 어떤 범위로 다루는지 실제 상담에서 확인하세요.

홈페이지 비용표가 현재 비용인가요?

자료의 기준과 현재 적용 여부를 확인해야 합니다. 실제 수강 조건에 따른 비용과 포함 범위를 지점에서 확인하세요.

체험 수업이 항상 가능한가요?

지점의 현재 운영에 따라 다릅니다. 가능 여부와 신청 조건을 확인하기 전에는 제공된다고 가정하지 마세요.
