분수와 소수는 먼저 하나의 수로 크기를 확인하세요. 전체가 무엇인지 정하고, 같은 크기의 단위나 수직선으로 비교한 뒤 계산 절차가 왜 맞는지 설명해 봅니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

분자와 분모를 따로 더하거나 소수 자릿수를 무시하는 오류는 계산 횟수를 늘리기 전에 단위를 확인해야 합니다. 그림에서 전체의 크기가 다르면 분수 크기 비교가 달라 보일 수 있으므로 같은 전체를 기준으로 두세요.

관련 학습 방법의 참고 범위는 IES 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 전체와 단위 정하기

    한 개의 전체를 같은 크기로 나눈 상황인지 확인합니다. 1/4은 전체를 네 부분으로 똑같이 나눈 것 중 한 부분이라는 뜻을 말해 봅니다.

  2. 수직선에서 위치 찾기

    0과 1 사이를 같은 길이로 나누어 1/2와 3/4를 표시합니다. 1보다 큰 분수도 수직선에 놓아 분수가 항상 1보다 작다는 생각을 점검합니다.

  3. 같은 단위로 비교하기

    1/2 = 2/4처럼 단위를 맞춘 이유를 그림이나 말로 설명합니다. 소수는 0.5가 5/10이라는 관계로 연결하되 배운 범위 안에서 확인합니다.

  4. 계산과 크기를 함께 점검하기

    1/2 + 1/4 = 3/4를 구한 뒤 답이 1/2보다 크고 1보다 작은지 확인합니다. 절차만 외우지 않고 같은 단위를 더했다는 이유를 적습니다.

PRACTICE EXAMPLE

1/2 + 1/4를 잘못 더했을 때

직접 작성한 문제입니다. “1/2 + 1/4 = 2/6”이라는 풀이를 고쳐 보세요.

풀이와 크기 점검 보기

1/2을 2/4로 바꾸면 2/4 + 1/4 = 3/4입니다. 분모 4는 단위의 크기를 나타내므로 같은 단위를 유지하고 분자만 더합니다. 2/6 = 1/3은 1/2보다 작아 양수를 더한 상황과 맞지 않습니다.

다른 분수에서도 같은 이유가 통하는지 확인하기

첫 예시의 답을 기억하는 것과 같은 단위의 의미를 이해하는 것은 다를 수 있습니다. 새로운 분수에서는 전체를 같게 두고 크기를 비교한 뒤 계산해 보세요. 그림을 썼다면 칸이 같은 크기인지, 식을 썼다면 어떤 공통 단위를 사용했는지 설명합니다. 분수와 소수의 표현을 바꿀 때에도 값이 같은지를 확인하고, 아직 배우지 않은 복잡한 변환은 별도의 학습으로 구분합니다.

다른 과제로 한 번 더

2/3과 3/4 중 큰 수를 찾고, 왜 그런지 공통 단위로 설명해 보세요. 비교 전에 각각 1/2보다 큰지와 1보다 작은지도 말해 봅니다.

확인 방향 보기

2/3 = 8/12, 3/4 = 9/12이므로 3/4가 더 큽니다. 분모 12가 같은 크기의 단위를 나타낸다는 이유를 설명하는지 확인하세요. 이유가 막히면 그림이나 수직선으로 돌아갈 수 있습니다.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 그림에서 전체의 크기가 같다.
  • 분수를 수직선에 놓아 보았다.
  • 통분하는 이유를 말할 수 있다.
  • 계산 답의 대략적인 크기를 확인했다.
