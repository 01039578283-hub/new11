수학 오답은 조건·경우·계산을 나누어 점검하세요

정답을 다시 쓰기 전에 어디에서 풀이가 달라졌는지 확인하세요. 문제의 조건을 놓쳤는지, 가능한 경우를 빠뜨렸는지, 계산 과정에서 실수했는지를 구분하면 다음에 물어볼 질문을 구체적으로 정리할 수 있습니다.

아래 문항은 점검 방법을 설명하기 위해 직접 만든 학습 예시입니다.

1. 나누기 전에 제외할 값을 확인했나요?

(x² − 1) ÷ (x − 1) = 2

  1. 분모가 0이 되면 식이 정의되지 않으므로 먼저 x ≠ 1을 적습니다.
  2. x ≠ 1에서 x² − 1 = (x − 1)(x + 1)이므로 왼쪽 식은 x + 1입니다.
  3. x + 1 = 2를 풀면 x = 1이지만, 처음 제외한 값이므로 이 방정식의 해는 없습니다.

다음 질문: 약분하거나 양변을 나누기 전에 어떤 값을 제외해야 하는지 설명할 수 있나요?

2. 가능한 경우를 모두 나누었나요?

|x − 2| = 3

  1. x − 2 = 3인 경우에는 x = 5입니다.
  2. x − 2 = −3인 경우에는 x = −1입니다.
  3. 원래 식에 넣으면 |5 − 2| = 3, |−1 − 2| = 3이므로 두 값 모두 해입니다.

다음 질문: 절댓값 안의 수가 양수인 경우와 음수인 경우를 모두 확인했나요?

3. 부호와 괄호를 유지하며 계산했나요?

−2(x − 3) + 4x = 10

  1. 분배하면 −2x + 6 + 4x = 10입니다. −2 × (−3)은 +6입니다.
  2. 동류항을 정리하면 2x + 6 = 10, 따라서 x = 2입니다.
  3. 원래 식에 넣으면 −2(2 − 3) + 4 × 2 = 2 + 8 = 10으로 확인됩니다.

다음 질문: 개념은 설명할 수 있는데 부호가 달라졌다면, 처음 달라진 계산 줄을 찾았나요?

초등 계산 점검 · 직접 작성한 예시

분수를 더할 때 같은 크기의 조각으로 바꾸었나요?

1/3 + 1/6을 계산하세요. 두 분수는 같은 크기의 전체를 기준으로 합니다.

초등 분수 풀이 보기

답: 1/2

  1. 1/3은 같은 전체를 여섯 조각으로 나누었을 때 2/6입니다.
  2. 2/6 + 1/6 = 3/6이므로 결과는 1/2입니다.
  3. 분모와 분자를 각각 더한 2/9는 같은 크기의 조각을 더한 결과가 아닙니다.

다음 질문: 분모를 6으로 바꾸는 이유와 1/3 = 2/6인 이유를 그림이나 말로 설명할 수 있나요?

중등 식 세우기 점검 · 직접 작성한 예시

직사각형의 둘레를 식에 모두 반영했나요?

둘레가 40cm인 직사각형에서 가로는 세로보다 4cm 깁니다. 세로의 길이를 구하세요.

중등 식 세우기 풀이 보기

답: 8cm

  1. 세로를 x cm로 놓으면 가로는 (x + 4) cm입니다.
  2. 가로와 세로가 각각 두 개이므로 2x + 2(x + 4) = 40입니다.
  3. 4x + 8 = 40에서 x = 8입니다. 가로는 12cm입니다.
  4. 2 × 8 + 2 × 12 = 40으로 원래 둘레와 일치하는지 확인합니다.

다음 질문: x와 x + 4가 각각 어떤 길이를 뜻하는지, 왜 두 번씩 더하는지 설명할 수 있나요?

고등 함수 조건 점검 · 직접 작성한 예시

함수의 가장 작은 값도 주어진 범위 안에서 찾았나요?

f(x) = (x − 2)² + 1에서 0 ≤ x ≤ 1일 때 f(x)의 최솟값을 구하세요.

고등 함수 조건 풀이 보기

답: 2

  1. x = 2를 넣으면 함수값은 1이지만, x = 2는 주어진 범위에 포함되지 않습니다.
  2. 0 ≤ x ≤ 1에서는 x가 2에 가장 가까운 값이 1입니다. 따라서 (x − 2)²는 x = 1에서 가장 작습니다.
  3. f(1) = (1 − 2)² + 1 = 2이므로 최솟값은 2입니다.
  4. 양 끝의 값 f(0) = 5, f(1) = 2를 확인하고, 범위 밖의 x = 2를 답에 사용하지 않았는지 점검합니다.

질문: Why did Mina walk to school?

영어 이유·근거 답안 보기

예시 답안: Because she missed the bus.

  1. 첫 문장에서 missed the bus와 walked to school 사이를 so가 연결합니다.

영어 대명사 답안 보기

예시 답안: His notebook.

  2. open to page ten이라는 내용은 공책의 페이지를 펼친 상태를 설명합니다.
  3. 따라서 이 지문에서 It은 his notebook을 가리킵니다. 가장 가까운 명사라는 이유만으로 cup을 고르지 않습니다.
