시험 2주 계획은 범위 목록, 현재 이해, 다시 확인할 날짜로 만드세요. 모든 단원을 같은 시간으로 나누기보다 설명하지 못한 개념과 반복되는 오류를 먼저 배치하고, 마지막에는 조건과 답안 표현을 점검합니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

아래 2주 구성은 조정용 예시이며 학교나 학생에게 정해진 최적 일정은 아닙니다. 시험 범위가 넓거나 남은 시간이 다르면 단계별 분량을 줄여 적용하세요. 새로운 교재를 끝내는 것보다 실제 학교 자료에서 빈틈을 확인하는 데 초점을 둡니다.

관련 학습 방법의 참고 범위는 IES 참고자료 · EEF 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 범위와 자료를 확정하기

    학교 공지와 수업 자료로 단원, 지문, 평가 유형을 확인합니다. 예상 범위는 따로 표시하고 확정된 범위를 우선 계획합니다.

  2. 혼자 설명할 수 있는지 확인하기

    각 범위에서 대표 문제나 질문 하나를 골라 자료 없이 답합니다. 정답 여부와 근거 설명을 따로 기록하고 도움이 필요한 부분을 표시합니다.

  3. 앞부분에 보완 과제 놓기

    첫 며칠은 부족한 개념과 자주 틀린 유형을 보완합니다. “오답 정리” 대신 “비교 대상과 단위를 빠뜨린 문제 다시 설명”처럼 행동을 적습니다.

  4. 며칠 뒤 다시 꺼내 보기

    한 번 확인한 내용을 다른 날 자료 없이 다시 풀거나 설명합니다. 다시 막히면 복습 날짜와 범위를 조정하고 답을 본 직후의 익숙함만으로 끝내지 않습니다.

  5. 끝부분에 실제 조건 연습하기

    학교가 안내한 형식에 맞춰 제한 시간과 답안 분량을 연습합니다. 마지막에는 준비물과 제출·답안 조건을 확인하고 계획이 밀렸다면 필수 범위를 우선합니다.

PRACTICE EXAMPLE

14일을 세 구간으로 나눈 조정용 예시

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 일정 예시입니다. 1~5일은 범위 확인과 빈틈 보완, 6~10일은 자료를 덮고 다시 풀기, 11~14일은 실제 형식 연습과 답안 점검으로 나눕니다.

6일째 다시 푼 분수 문제에서 같은 오류가 나면 7일의 새 문제 일부를 줄이고 개념을 다시 설명합니다. 이 날짜 배치 자체가 성적 향상을 보장하거나 모든 학생에게 최적이라는 뜻은 아닙니다.

계획이 밀렸을 때 다시 배치하는 연습

진도가 밀린 날에는 못 한 항목을 모두 다음 날로 옮기기 전에 그 과제의 목적을 확인합니다. 같은 개념을 반복하는 과제, 새로 확인해야 하는 개념, 제출 마감이 있는 과제를 구분하세요. 필수 범위를 남기고 중복 연습 일부를 줄일 수 있습니다. 다만 자료 없이 확인하는 과제를 전부 없애면 이해한 정도를 판단하기 어려워질 수 있으므로 짧게라도 남겨 보세요.

다른 과제로 한 번 더

하루 계획에서 과제 세 개를 골라 “반드시 확인”, “분량 조정 가능”, “다른 날 가능”으로 분류합니다. 학교의 확정된 마감과 현재 이해를 근거로 이유를 적습니다.

확인 방향 보기

쉬운 과제만 남기지 않았는지, 약한 개념을 보완할 자리가 있는지 확인합니다. 우선순위를 혼자 정하기 어렵다면 실제 범위 목록과 확인 결과를 교사에게 보여 주세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 확정된 시험 범위를 기준으로 적었다.
  • 자료 없이 확인한 결과가 있다.
  • 같은 내용을 다시 볼 날짜가 있다.
  • 밀렸을 때 줄일 과제와 필수 과제를 정했다.
