시험 시간이 모자랄 때, 어디서 늦어졌는지 찾기

중학생고등학생

온담학습 학습안내 · 작성·자료 확인 2026-10-04

시간 부족은 읽기, 풀이 시작, 계산, 선택지 판단과 답안 작성 중 어디에서 생기는지 먼저 구분하세요. 실제 시험 규칙 안에서 보류할 문제를 정하고, 연습 기록으로 시간 배분을 조정하는 것이 필요합니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

문항 수로 시간을 똑같이 나누면 서술형이나 긴 지문의 특성을 놓칠 수 있습니다. 계산 속도만 높이려 하기보다 문제를 이해했는지, 같은 줄을 반복해 읽었는지, 답안 옮기기에 시간이 들었는지 나누어 살펴보세요.

관련 학습 방법의 참고 범위는 EEF 참고자료 · IES 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 실제 조건 확인하기

    시험 시간, 문항 구성, 답안 작성 방식과 허용 도구를 확인합니다. 학교가 정한 응시 규칙을 기준으로 연습하고 임의의 고정 시간표를 정답처럼 적용하지 않습니다.

  2. 구간별 소요를 기록하기

    연습할 때 문제 읽기, 풀이, 답안 작성의 대략적인 소요를 적습니다. 기록 때문에 풀이가 끊기면 한 묶음을 마친 뒤 돌아보는 방식으로 조정합니다.

  3. 보류 신호 정하기

    조건은 읽었지만 풀이 시작이 떠오르지 않거나 같은 계산을 반복하면 표시하고 다음 문제로 넘어갈 기준을 정합니다. 돌아올 때 찾을 수 있게 문제 위치와 진행한 줄을 남깁니다.

  4. 답안 확인 시간을 남기기

    마지막 점검에서 번호, 단위, 부호와 요구한 답의 형식을 확인합니다. 연습에서 실제로 걸린 시간을 보고 점검 시간을 조정합니다.

  5. 늦어진 원인 하나 보완하기

    근거를 못 찾은 독해와 부호를 반복 수정한 계산은 다른 과제입니다. 다음 연습에는 해당 원인을 보완한 뒤 같은 조건에서 변화가 있는지 살펴봅니다.

PRACTICE EXAMPLE

넘어갈 기준을 풀이 흔적으로 정하기

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 연습 예시입니다. 식을 두 번 세웠는데 같은 조건을 빠뜨렸다면 “조건 표시 후 보류”라고 기록합니다. 다음 문제를 풀고 돌아왔을 때 처음부터 읽는 대신 표시한 조건과 식을 먼저 비교합니다.

보류가 늘어 정답률이 떨어졌다면 기준을 다시 조정합니다. 특정 초 단위로 무조건 넘기는 규칙보다 자신의 풀이 기록과 시험 구성을 확인하세요.

넘어갈 기준을 풀이 흔적으로 정하기 — 확인표
늦어진 구간확인할 흔적다음 연습
문제 읽기조건을 반복해서 읽음구하는 것과 조건을 구분
풀이 진행같은 계산을 여러 번 수정부호·단위·식을 먼저 점검
답안 작성번호·형식을 다시 고침답 옮기기와 최종 확인 연습

답안 옮기기까지 포함한 짧은 연습

문제를 풀었더라도 번호를 잘못 옮기거나 요구한 단위를 빠뜨리면 답안 확인이 필요합니다. 연습에서는 풀이 시간만 재지 말고 실제 답안 작성 방식도 포함해 보세요. 문항 형식과 시험 규칙에 맞는 작은 묶음으로 시작하고, 보류한 문제를 다시 찾는 과정도 확인합니다. 시간을 줄이는 방법을 시험 규칙 밖의 도구나 허용되지 않은 표시로 적용하지 않습니다.

다른 과제로 한 번 더

이미 배운 문제 몇 개를 실제 답안 형식으로 작성하고 마지막에 번호, 부호, 단위와 질문의 대상을 확인해 보세요. 확인 중 발견한 오류를 따로 적습니다.

확인 방향 보기

점검이 형식적인 훑기로 끝나지 않고 실제 오류를 찾았는지 봅니다. 같은 유형에서 시간이 계속 늘어나면 속도 목표를 낮추고 조건 해석이나 계산 단계의 어려움을 확인하세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 시험의 실제 응시 규칙을 확인했다.
  • 시간 부족의 구간을 구분했다.
  • 보류한 문제를 다시 찾을 표시가 있다.
  • 점검 시간을 실제 연습 결과로 조정했다.
