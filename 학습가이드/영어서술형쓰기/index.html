온담학습 학습안내 · 작성·자료 확인 2026-10-04

영어 서술형은 질문이 요구한 내용과 사용해야 할 표현을 먼저 확인하세요. 짧은 초안으로 의미를 완성한 뒤 주어·동사, 시제, 단어 수와 형식 조건을 점검합니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

어려운 문장을 길게 쓰는 것보다 질문에 정확히 답하는 것이 먼저입니다. 이 글의 점검 틀은 실제 학교의 채점 기준을 대신하지 않습니다. 주어진 단어, 문장 수와 허용된 형태는 문제 안내를 그대로 확인하세요.

관련 학습 방법의 참고 범위는 British Council 참고자료 · IES 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 내용과 형식 조건 나누기

    무엇을 설명해야 하는지와 사용 표현, 시제, 단어 수 같은 조건을 따로 적습니다. 조건끼리 충돌해 보이면 임의로 판단하지 말고 교사에게 확인합니다.

  2. 주어와 행동으로 초안 쓰기

    누가 무엇을 했는지부터 짧게 적습니다. 필요한 이유나 비교를 더하되 이해하지 못한 어려운 표현을 그대로 끼워 넣지 않습니다.

  3. 문장 형태를 순서대로 확인하기

    중심 주어와 서술어, 시제, 명사 수와 연결 표현을 확인합니다. 내용을 고친 뒤 문법을 다시 점검해 의미와 형태가 맞는지 봅니다.

  4. 문제 조건으로 최종 점검하기

    질문에 답했는지, 필요한 표현을 썼는지, 철자와 구두점이 맞는지 확인합니다. 모범 답안은 구조를 참고하되 자신의 답을 그대로 대조해 봅니다.

PRACTICE EXAMPLE

이유를 because로 쓰는 답안

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 문제입니다. “왜 도서관에서 공부하나요?”에 because를 사용해 영어 한 문장으로 답해 보세요.

예시 답안은 “I study in the library because it is quiet.”입니다. 공부하는 행동과 조용하다는 이유가 연결되고, it은 the library를 가리킵니다. 실제 문제에서 요구한 다른 조건이 있다면 추가로 확인해야 합니다.

조건 하나를 바꿔 새 답안 만들기

모범 문장을 기억했다면 질문의 대상이나 이유를 바꾸어 직접 답해 보세요. 바뀐 조건에 맞게 대명사와 동사도 달라지는지 확인합니다. 긴 문장을 만들다가 뜻이 흐려지면 먼저 짧은 문장으로 질문에 답하고 필요한 이유를 붙입니다. 실제 평가에서 주어진 표현의 변형이 허용되는지, 문장 수와 단어 수가 어떻게 정해져 있는지는 문제 안내를 우선합니다. 아래 연습의 답이 실제 학교에서 인정되는 채점 기준은 아닙니다.

직접 작성한 답안 예시는 “We walk to school because there is no bus.”입니다. 주어와 행동, 이유가 연결됩니다. 자신이 쓴 다른 문장도 뜻과 형태가 맞는지 확인하고 실제 과제의 추가 조건을 대조하세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 내용과 형식 조건을 구분했다.
  • 질문에 직접 답하는 문장을 썼다.
  • 주어·서술어와 시제를 확인했다.
  • 철자와 실제 문제 조건을 다시 봤다.

자주 묻는 질문

예시 답안을 외우면 되나요?

문제의 내용과 조건이 달라질 수 있습니다. 예시의 구조를 이해하고 새로운 상황에 맞게 직접 문장을 써 보세요.

문법부터 고쳐야 하나요?

먼저 질문에 필요한 내용이 있는지 확인하세요. 내용이 정리된 뒤 문장의 형태와 형식 조건을 순서대로 점검할 수 있습니다.

부모가 영어 답을 써 줘도 되나요?

학생이 자신의 문장을 만들고 설명하도록 돕는 편이 좋습니다. 수행평가라면 학교가 허용한 도움 범위를 먼저 확인하세요.
