수학

함수 그래프, 모양보다 축과 변화부터 읽기

중학생고등학생

온담학습 학습안내 · 작성·자료 확인 2026-10-04

그래프는 먼저 가로축과 세로축이 무엇인지, 눈금과 범위가 어떤지 확인하세요. 한 점의 의미와 값의 변화 관계를 말한 뒤 표·식과 연결하고, 그림 밖의 값을 임의로 단정하지 않습니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

선이 올라간다는 말만으로 기울기나 증가량을 설명할 수는 없습니다. 눈금이 달라지면 그림의 인상도 달라집니다. 실제 자료 그래프와 수학의 함수 그래프는 조건과 해석 범위를 확인해 구분하세요.

관련 학습 방법의 참고 범위는 IES 참고자료 · IES 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 축·눈금·범위 읽기

    각 축의 변수와 단위, 눈금 간격을 확인합니다. 문제에서 정의한 입력 범위나 제외한 값이 있는지도 먼저 표시합니다.

  2. 한 점을 문장으로 설명하기

    좌표 (2, 5)가 입력 2에 출력 5라는 뜻임을 말합니다. 실생활 상황이면 어떤 양이 2일 때 무엇이 5인지 단위를 붙입니다.

  3. 표에서 변화 확인하기

    몇 개의 입력과 출력을 표로 적습니다. 입력 변화에 출력이 어떻게 달라지는지 보고, 일정한 변화인지 구간에 따라 다른지 확인합니다.

  4. 식과 범위를 함께 점검하기

    식을 세웠다면 표의 값과 대조합니다. 계산 가능한 식이 있어도 상황이나 문제 조건에서 허용한 범위를 벗어나지 않았는지 확인합니다.

PRACTICE EXAMPLE

y = 2x + 1을 표와 연결하기

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 예시입니다. x가 0, 1, 2일 때 y = 2x + 1의 값은 각각 1, 3, 5입니다. 입력이 1 늘 때 출력이 2 늘어나는 관계를 확인합니다.

문제가 x를 0 이상 2 이하로 제한했다면 식에 x = 10을 대입할 수 있어도 그 문제의 그래프 범위에 포함되지는 않습니다. 그림의 범위와 식 자체의 성질을 구분하세요.

그래프 밖의 값을 말할 때 조건 확인하기

식이 있어도 실제 상황에서 입력할 수 있는 값은 제한될 수 있습니다. 사람 수나 물건 수처럼 정수만 가능한지, 시간이 음수가 될 수 있는지 문제 조건을 읽어 보세요. 그래프의 점을 연결한 선이 실제로 모든 입력을 허용하는지 확인하고, 식을 이용한 계산과 상황의 가능한 값은 구분해서 설명합니다. 축의 눈금이 다르면 같은 관계도 그림에서 달라 보일 수 있습니다.

다른 과제로 한 번 더

y = 3x + 2에서 x가 0, 1, 2일 때 표를 만들고 입력이 1 늘 때 출력의 변화를 말해 보세요. 이후 x가 0 이상 2 이하인 조건을 붙여 봅니다.

확인 방향 보기

출력은 2, 5, 8이고 입력이 1 늘 때 출력은 3 늘어납니다. 제한 조건이 있다면 x = 4의 계산 결과 14를 그 문제의 허용 범위 안의 값으로 쓰지는 않습니다. 점·표·식과 조건을 함께 확인하세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 축의 변수와 단위를 확인했다.
  • 눈금과 입력 범위를 표시했다.
  • 점을 문장으로 설명했다.
  • 표·식·그래프가 같은 관계를 나타낸다.

자주 묻는 질문

선이 가파르면 무조건 변화가 큰가요?

축의 단위와 눈금이 같은지 확인해야 합니다. 그림의 기울어진 인상만으로 서로 다른 그래프를 비교하지 마세요.

점 몇 개가 맞으면 식이 확정되나요?

가능한 함수 형태와 문제 조건을 함께 확인해야 합니다. 몇 점에 맞는 식이 여러 개일 수 있으므로 조건 없이 하나로 단정하지 마세요.

실제 통계 그래프도 같은 방법으로 읽나요?

축, 단위와 범위 확인은 공통으로 도움이 됩니다. 다만 통계 자료에서는 표본과 조사 조건, 관찰 범위도 별도로 확인해야 합니다.
