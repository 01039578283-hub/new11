과학 자료는 축과 단위, 측정 조건을 먼저 확인한 뒤 실제로 관찰한 값을 설명하세요. 개념으로 이유를 연결하되 측정한 범위를 벗어난 예측과 관찰 사실을 구분합니다.

먼저 살펴볼 점실행 순서예시·확인표추가 연습점검 질문실천 기록궁금한 점참고자료

먼저 살펴볼 점

그림이나 모형은 개념을 이해하는 도구이지만 실제 현상의 모든 특징을 나타내지는 않습니다. 그래프에서도 선의 모양만 보지 말고 측정값과 조건을 확인하세요. 예상과 다른 값은 지우기보다 확인할 조건을 남깁니다.

관련 학습 방법의 참고 범위는 EEF 참고자료에서 확인할 수 있습니다. 아래 절차와 예시는 학교 자료와 현재 과제에 맞춰 조정해 보세요.

내 과제에 적용하는 순서

  1. 변수와 단위를 읽기

    가로축과 세로축이 무엇인지, 어떤 단위를 쓰는지 확인합니다. 눈금 간격과 측정 범위를 적고 그래프 제목만으로 뜻을 단정하지 않습니다.

  2. 관찰한 변화 먼저 쓰기

    값이 어느 구간에서 어떻게 달라졌는지 자료 그대로 설명합니다. 변화를 설명하는 개념은 그다음에 붙입니다.

  3. 실험 조건과 비교하기

    바꾼 조건, 같게 유지한 조건과 측정한 것을 구분합니다. 여러 조건이 함께 달라졌다면 한 조건만 원인으로 확정하기 어렵다는 점을 표시합니다.

  4. 모형과 예측의 한계 밝히기

    모형이 나타내는 부분과 생략한 부분을 확인합니다. 측정하지 않은 구간의 값은 예상이라고 밝히고 실제 관찰값처럼 쓰지 않습니다.

PRACTICE EXAMPLE

가상 온도 표를 읽는 순서

온담학습이 직접 작성한 연습용 예시입니다. 실제 학생 사례·성적·학교 출제 자료를 뜻하지 않습니다.

직접 작성한 가상 측정 예시입니다. 같은 용기 속 물의 온도가 0분 20℃, 2분 24℃, 4분 28℃로 기록되어 있다고 가정합니다.

이 자료에서는 2분 간격으로 4℃씩 높아진 관찰을 말할 수 있습니다. 6분에도 반드시 32℃라고 단정하거나, 다른 용기에서도 같은 변화라고 말하려면 추가 측정과 조건 확인이 필요합니다. 실제 실험 결과가 아닙니다.

가상 온도 표를 읽는 순서 — 확인표
시간가상 온도확인할 점
0분20℃측정 시작 조건
2분24℃같은 조건과 측정 방법
4분28℃관찰 범위 밖 예측과 구분

관찰과 원인 설명을 두 문장으로 나누기

자료의 변화와 그 원인을 같은 문장에 바로 묶으면 확인하지 않은 조건을 지나칠 수 있습니다. 먼저 값이 어떻게 달라졌는지 쓰고, 그다음 설명에 필요한 개념과 조건을 적어 보세요. 실험에서 여러 조건이 달라졌다면 하나만 원인으로 말하기 어렵습니다. 관찰값이 예상과 다를 때는 결과를 지우지 말고 측정 방법과 시작 조건을 확인합니다. 모형을 사용한 설명이라면 실제 현상에서 생략된 특징이 무엇인지도 표시할 수 있습니다.

다른 과제로 한 번 더

가상 자료에서 조건 A의 측정값은 5, 조건 B의 측정값은 7이라고 적혀 있습니다. “B가 더 크다”와 “특정 조건 때문에 커졌다”를 나누어 쓰고 단위와 비교 조건을 질문해 보세요.

확인 방향 보기

값의 비교는 할 수 있지만 단위와 실험 조건이 없으면 의미와 원인을 충분히 설명하기 어렵습니다. 바꾼 변수와 같게 유지한 조건을 확인한 뒤 자료 범위 안에서 결론을 정하세요.

끝내기 전에 확인할 질문

각 문장을 내 과제로 확인해 보세요. 체크 수로 능력이나 상태를 판정하는 검사가 아닙니다.

  • 축과 단위를 확인했다.
  • 관찰값과 이유 설명을 구분했다.
  • 바꾼 조건과 유지한 조건을 적었다.
  • 측정 밖의 값을 관찰값처럼 쓰지 않았다.

자주 묻는 질문

그래프가 곧으면 계속 같은 변화인가요?

관찰한 범위와 실험 조건을 확인해야 합니다. 측정하지 않은 구간에서도 같은 관계가 이어진다고 자동으로 단정하지 마세요.

예상과 다른 값은 빼도 되나요?

임의로 지우지 말고 측정 과정과 조건을 확인하세요. 제외 기준이 있다면 그 기준과 이유를 명확히 기록해야 합니다.

모형은 실제와 완전히 같나요?

모형은 특정 특징을 설명하도록 단순화한 표현입니다. 무엇을 보여 주고 무엇을 생략했는지 함께 확인하세요.
